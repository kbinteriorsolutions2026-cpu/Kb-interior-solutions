KB INTERIOR SOLUTIONS — PWA STARTER

Included:
- index.html: business app
- logo.png: supplied company logo
- manifest.webmanifest + app icons: installable web app metadata
- sw.js: offline cache after first successful load

IMPORTANT:
1. This is a Progressive Web App (PWA) starter, not an Android APK.
2. For install/offline caching, host these files on an HTTPS website (or localhost for testing).
3. Open the hosted site in Chrome on Android, then use the browser menu > "Install app" or "Add to Home screen".
4. App records are saved in browser local storage on that device. Export a JSON backup regularly.
5. Cloud sync is not configured yet. Password lock is a basic screen lock and does not encrypt stored records.
6. Do not rely on this starter for sensitive data until stronger authentication, encrypted storage, backup and restore have been tested.

Company details are prefilled in the app.
